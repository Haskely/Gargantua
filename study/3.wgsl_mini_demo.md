# WGSL 最小教学样例

## 需求

请在 study/3.wgsl_mini_demo 编写最小可运行的单文件 HTML 教学样例，用 WebGPU + WGSL 实时渲染一个随时间、鼠标变化的颜色（像 Shadertoy 入门那样）

要求：
1. 代码尽量满足最新规范和标准，无论是 html 还是 wgsl 等
2. 添加必要且详细的教学性中文注释

## 项目介绍

这是一个 WebGPU + WGSL 的最小化教学示例，展示了如何使用现代 GPU 图形 API 创建交互式实时渲染效果。

### 实现功能

- ✅ **矩形渲染**: 使用 6 个顶点(2个三角形)渲染一个居中的长方形
- ✅ **实时动画**: 基于时间的颜色动画效果，包含正弦波和余弦波
- ✅ **鼠标交互**: 鼠标移动会改变渲染颜色和波纹效果
- ✅ **波纹特效**: 以鼠标位置为中心的动态波纹效果
- ✅ **Uniform 传值**: 演示了如何从 CPU 向 GPU 传递数据(时间、鼠标坐标)

### 技术要点

1. **WebGPU 初始化**: 完整的设备、适配器、上下文配置流程
2. **WGSL 着色器**: 顶点着色器和片段着色器的协同工作
3. **Uniform Buffer**: GPU 数据绑定和更新机制
4. **渲染管线**: 完整的渲染管线创建和配置
5. **动画循环**: 基于 `requestAnimationFrame` 的渲染循环

### 使用方法

直接在支持 WebGPU 的浏览器(Chrome 113+ 或 Edge 113+)中打开 [`index.html`](3.wgsl_mini_demo/index.html) 即可运行。

移动鼠标可以看到颜色和波纹的变化效果。
