## 📖 关于本书

本书是一本系统性的 WebGPU 和 WGSL 教程，专为零基础学习者设计。无论您是否听说过"着色器"，本书都将带您从最基本的图形学概念出发，一步步进入现代 Web GPU 编程的世界。

### 🎯 核心特色

- **💡 零基础友好**：不需要任何图形学背景，从零开始讲解
- **🎨 实战驱动**：通过完整的交互式项目学习所有知识点
- **📐 深入浅出**：复杂概念用通俗易懂的方式解释
- **🔗 知识串联**：系统化的学习路径，循序渐进
- **💻 代码详解**：每一行代码都有详细注释和解释
- **🚀 进阶指引**：为后续深入学习提供清晰路径

### 🎓 适合人群

- Web 开发者想学习 GPU 编程
- 对计算机图形学感兴趣的初学者
- 希望掌握 WebGPU 技术的前端工程师
- 想要创建交互式图形应用的开发者
- 游戏开发、数据可视化领域的从业者

### 📦 学习收获

完成本书学习后，您将能够：

✅ 理解 GPU 渲染管线的工作原理
✅ 使用 WGSL 编写顶点和片段着色器
✅ 创建实时动画和交互式图形效果
✅ 掌握 CPU 与 GPU 之间的数据传递
✅ 实现复杂的视觉特效和程序化图形
✅ 具备继续学习 3D 渲染和计算着色器的基础

## 🎯 学习建议

### 📅 学习路径

**第一阶段（1-2周）：建立基础**
- 阅读第1-2章，理解基本概念
- 搭建开发环境
- 运行第一个WebGPU程序

**第二阶段（2-3周）：掌握核心**
- 学习第3-5章，理解着色器编程
- 掌握数据传递机制
- 完成所有章节练习

**第三阶段（2-3周）：实战应用**
- 学习第6-7章，实现动画和交互
- 独立完成项目
- 尝试创造性修改

**第四阶段（持续）：深入进阶**
- 学习第8-9章，总结和进阶
- 探索3D渲染和计算着色器
- 参与开源项目

### 💡 学习技巧

1. **动手实践**：每个知识点都要亲自编写代码验证
2. **理解原理**：不要死记硬背，理解背后的原理
3. **循序渐进**：按章节顺序学习，不要跳过基础
4. **反复练习**：多次重复关键概念和代码
5. **项目驱动**：通过实际项目巩固知识
6. **社区交流**：遇到问题积极寻求帮助

### 🔧 推荐工具

- **代码编辑器**：VS Code（推荐安装WGSL语法高亮插件）
- **浏览器**：Chrome 113+ 或 Edge 113+
- **调试工具**：Chrome DevTools
- **数学库**：gl-matrix（矩阵运算）
- **版本控制**：Git
