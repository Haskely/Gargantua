### WebGPU + WGSL 从入门到实践：现代 Web 图形编程指南

---

#### **书籍简介**

本书是一本面向零基础学习者的 WebGPU 和 WGSL 入门教程。无论你是否听说过“着色器”，本书都将带你从最基本的图形学概念出发，一步步进入现代 Web GPU 编程的世界。我们将通过一个贯穿全书的交互式渲染案例，深入剖析每一行代码背后的原理，让你不仅能“知其然”，更能“知其所以然”。

**核心教学案例**：一个随时间、鼠标交互而实时变化的动态着色效果（基于 `study/3.wgsl_mini_demo/index.html`）。

---

### **第一部分：基础概念入门 (The Big Picture)**

#### **第 1 章：欢迎来到 GPU 的世界**

*   **核心学习目标**：
    *   理解 GPU 是什么，以及它与 CPU 的区别。
    *   了解什么是图形渲染管线（简单概念版）。
    *   建立对“着色器 (Shader)”的初步认知。
*   **内容要点**：
    *   1.1 为什么我们需要 GPU？（并行计算的力量）
    *   1.2 想象一下 GPU 的工作流程：一个“像素工厂”
    *   1.3 什么是着色器？给“像素工厂”编写指令的程序员
    *   1.4 Web 上的图形技术简史：从 Flash 到 WebGPU（参考 `1.intro.md`）
    *   **思考题**：尝试用生活中的例子解释 CPU 和 GPU 的工作模式差异。

### **第二部分：第一个 WebGPU 程序**

#### **第 2 章：搭建你的第一个 WebGPU 应用**

*   **核心学习目标**：
    *   完成 WebGPU 的初始化流程。
    *   在浏览器中绘制出第一个纯色背景。
    *   理解适配器、设备、上下文的核心作用。
*   **概念与代码组织**：
    *   **理论**：详细解释 `navigator.gpu`、`adapter`、`device`、`context` 的层级关系和作用。
    *   **代码**：逐行讲解 `index.html` 中的 `initWebGPU` 函数。
*   **内容要点**：
    *   2.1 环境准备：你需要一个现代浏览器
    *   2.2 代码骨架：创建一个 HTML 文件
    *   2.3 步骤一：请求 GPU 适配器 (`requestAdapter`)
    *   2.4 步骤二：获取逻辑设备 (`requestDevice`)
    *   2.5 步骤三：连接 Canvas 画布 (`getContext('webgpu')`)
    *   2.6 步骤四：配置上下文 (`context.configure`)
    *   2.7 渲染一个“清屏”背景色
    *   **练习**：尝试修改清屏颜色。

#### **第 3 章：你好，WGSL！编写你的第一个着色器**

*   **核心学习目标**：
    *   理解顶点着色器和片段着色器的作用。
    *   编写一个最简单的 WGSL 着色器，绘制一个纯色三角形。
    *   了解 WGSL 的基本语法结构。
*   **概念与代码组织**：
    *   **理论**：解释图形渲染中的顶点数据和片元（像素）颜色。
    *   **代码**：拆解 `index.html` 中 `shaderCode` 的 `vertexMain` 和 `fragmentMain` 函数，先从最简版本开始。
*   **内容要点**：
    *   3.1 什么是 WGSL？现代化的着色器语言
    *   3.2 顶点着色器 (`@vertex`)：告诉 GPU 画什么形状
    *   3.3 片段着色器 (`@fragment`)：告诉 GPU 每个像素是什么颜色
    *   3.4 WGSL 基础语法：函数、变量、数据类型 (`vec4f`, `f32`)
    *   3.5 将 WGSL 代码加载到 WebGPU 中 (`createShaderModule`)
    *   **练习**：修改片段着色器，输出一个固定的彩色（如红色）。

#### **第 4 章：连接 CPU 与 GPU：渲染管线**

*   **核心学习目标**：
    *   理解渲染管线的概念。
    *   创建一个完整的渲染管线，将顶点和片段着色器连接起来。
    *   完成第一次绘制调用 (`draw`)。
*   **概念与代码组织**：
    *   **理论**：将渲染管线比喻成一条“装配线”，输入是数据，输出是图像。
    *   **代码**：逐行讲解 `index.html` 中的 `createRenderPipeline` 和 `render` 函数的核心绘制部分。
*   **内容要点**：
    *   4.1 什么是渲染管线 (`Render Pipeline`)？
    *   4.2 定义管线布局 (`createPipelineLayout`)
    *   4.3 创建渲染管线 (`createRenderPipeline`)
    *   4.4 渲染循环 (`requestAnimationFrame`) 的重要性
    *   4.5 命令编码器 (`Command Encoder`)：给 GPU 下达指令
    *   4.6 渲染通道 (`Render Pass`)：在哪里绘制
    *   4.7 执行绘制！(`renderPass.draw(3)`)
    *   **练习**：修改顶点着色器的坐标，改变三角形的形状。

### **第三部分：让画面动起来**

#### **第 5 章：传递数据给着色器 (Uniform Buffer)**

*   **核心学习目标**：
    *   理解为什么需要从 CPU 向 GPU 传递数据。
    *   掌握 `Uniform Buffer` 的工作原理和使用方法。
    *   实现一个基于时间变化的颜色动画。
*   **概念与代码组织**：
    *   **理论**：解释 GPU 内存与 CPU 内存的隔离，以及 Uniform Buffer 作为沟通桥梁的作用。
    *   **代码**：深入讲解 `shaderCode` 中的 `Uniforms` 结构体、`@group(0) @binding(0)`，以及 `createRenderPipeline` 和 `render` 函数中与 `uniformBuffer` 相关的部分。
*   **内容要点**：
    *   5.1 静态 vs 动态：为什么需要 Uniform？
    *   5.2 WGSL 中的数据结构 (`struct`)
    *   5.3 绑定布局 (`BindGroupLayout`) 和绑定组 (`BindGroup`)：数据的“插座”和“插头”
    *   5.4 创建 `GPUBuffer`：在 GPU 上开辟内存
    *   5.5 更新数据：`device.queue.writeBuffer`
    *   5.6 在 WGSL 中使用 `uniforms.time` 实现颜色动画
    *   **练习**：尝试用 `time` 控制三角形的位置或大小。

#### **第 6 章：交互的魔法：响应鼠标输入**

*   **核心学习目标**：
    *   将鼠标坐标传递给着色器。
    *   实现与用户交互的实时视觉效果。
*   **概念与代码组织**：
    *   **理论**：讲解屏幕坐标系与归一化设备坐标系 (NDC) 的转换。
    *   **代码**：分析 `index.html` 中的 `mousemove` 事件监听器，以及 `uniforms.mouseX` 和 `mouseY` 在 WGSL 中的应用。
*   **内容要点**：
    *   6.1 监听 JavaScript 事件：`addEventListener`
    *   6.2 坐标系转换：从像素坐标到 `0-1` 范围
    *   6.3 将鼠标坐标写入 Uniform Buffer
    *   6.4 在 WGSL 中使用鼠标坐标：`uniforms.mouseX`, `uniforms.mouseY`
    *   6.5 创造互动效果：用鼠标位置改变颜色或形状
    *   **思考题**：除了颜色，鼠标还能控制哪些视觉效果？

### **第四部分：深入 WGSL 与图形效果**

#### **第 7 章：探索 WGSL 内置函数与数学之美**

*   **核心学习目标**：
    *   学习常用的 WGSL 数学函数，如 `sin`, `cos`, `distance`, `mix`。
    *   理解 UV 坐标系。
    *   实现更复杂的视觉效果，如波纹和渐变。
*   **概念与代码组织**：
    *   **理论**：介绍程序化生成艺术 (Procedural Art) 的基本思想，以及数学函数在其中的应用。
    *   **代码**：详细分析 `fragmentMain` 中颜色计算和波纹效果的每一行 WGSL 代码。
*   **内容要点**：
    *   7.1 什么是 UV 坐标？给每个像素一个“地址”
    *   7.2 `sin` 和 `cos`：创造平滑的周期性动画
    *   7.3 `distance`：计算距离，创造圆形/径向效果
    *   7.4 `mix` / `lerp`：平滑过渡和颜色混合
    *   7.5 案例剖析：`index.html` 中的波纹效果是如何实现的
    *   **练习**：尝试调整波纹的频率、振幅，或创造一种全新的颜色混合模式。
