
# 第三章 深入理解顶点着色器

## 3.1 顶点着色器在渲染管线中的位置

在WebGPU渲染管线中，顶点着色器是第一个可编程的阶段。它的主要职责是处理每个顶点的数据，将模型空间中的顶点位置转换为裁剪空间坐标。

### 渲染管线流程

```
输入汇编器 → 顶点着色器 → 几何处理 → 光栅化 → 片段着色器 → 输出合并
     ↑           ↑                                    ↑
   顶点数据    坐标转换                             像素着色
```

**顶点着色器的核心任务：**
1. 接收顶点数据（位置、颜色、纹理坐标等）
2. 进行坐标空间转换（模型空间 → 裁剪空间）
3. 计算并传递数据到片段着色器
4. 为每个顶点执行一次（GPU并行处理）

### GPU并行处理概念

顶点着色器是在GPU上并行执行的。假设我们有6个顶点：

```
CPU发送绘制命令（draw 6个顶点）
          ↓
GPU同时启动多个着色器实例
          ↓
┌─────────┬─────────┬─────────┬─────────┬─────────┬─────────┐
│顶点0    │顶点1    │顶点2    │顶点3    │顶点4    │顶点5    │
│vertexMain│vertexMain│vertexMain│vertexMain│vertexMain│vertexMain│
└─────────┴─────────┴─────────┴─────────┴─────────┴─────────┘
          ↓
每个实例处理一个顶点，同时执行
          ↓
输出6个变换后的顶点数据
```

## 3.2 顶点着色器输出结构体

在分析顶点着色器主函数之前，我们先理解它的输出数据结构（[`index.html`](study/3.wgsl_mini_demo/index.html:101-104)）：

```wgsl
struct VertexOutput {
    @builtin(position) position: vec4f,  // 裁剪空间坐标
    @location(0) uv: vec2f,              // UV 坐标（传递到片段着色器）
}
```

### 逐行解析

**第1行：`struct VertexOutput {`**
- `struct` 是WGSL的结构体关键字，类似C语言
- `VertexOutput` 是自定义的结构体名称
- 这个结构体定义了顶点着色器输出的数据格式

**第2行：`@builtin(position) position: vec4f,`**
- `@builtin(position)` 是一个装饰器（attribute）
  - 告诉GPU这个字段是顶点的最终裁剪空间位置
  - 必须使用此装饰器，GPU才知道如何进行后续的几何处理
- `position` 是字段名称（可以自定义）
- `vec4f` 是4维浮点向量类型（x, y, z, w）
  - x, y: 屏幕上的水平和垂直位置
  - z: 深度值（用于深度测试）
  - w: 齐次坐标的缩放因子（通常为1.0）

**第3行：`@location(0) uv: vec2f,`**
- `@location(0)` 指定这是第0个用户自定义输出
  - 可以有多个location（0, 1, 2...）用于传递不同数据
  - 片段着色器需要用相同的location来接收
- `uv` 是纹理坐标变量名
- `vec2f` 是2维浮点向量（u, v）
  - 范围通常是0到1
  - 用于纹理采样或渐变计算

## 3.3 顶点着色器主函数详解

现在我们来逐行分析顶点着色器的核心代码（[`index.html`](study/3.wgsl_mini_demo/index.html:109-131)）：

```wgsl
@vertex
fn vertexMain(@builtin(vertex_index) vertexIndex: u32) -> VertexOutput {
    var output: VertexOutput;

    // 定义矩形的6个顶点坐标（2个三角形）
    var positions = array<vec2f, 6>(
        vec2f(-0.6, -0.6),  // 左下
        vec2f(0.6, -0.6),   // 右下
        vec2f(0.6, 0.6),    // 右上
        vec2f(-0.6, -0.6),  // 左下
        vec2f(0.6, 0.6),    // 右上
        vec2f(-0.6, 0.6)    // 左上
    );

    let pos = positions[vertexIndex];
    output.position = vec4f(pos, 0.0, 1.0);

    // 将裁剪空间坐标转换为 UV 坐标 (0 到 1)
    output.uv = vec2f((pos.x + 1.0) * 0.5, (1.0 - pos.y) * 0.5);

    return output;
}
```

### 函数签名解析

**第1行：`@vertex`**
- 这是一个装饰器，标记此函数为顶点着色器入口点
- WebGPU在绘制时会自动调用这个函数
- 每个渲染管线只能有一个@vertex函数

**第2行：`fn vertexMain(@builtin(vertex_index) vertexIndex: u32) -> VertexOutput {`**

分解这一行：

1. `fn vertexMain` - 定义函数名为vertexMain（名称可自定义）

2. `@builtin(vertex_index) vertexIndex: u32` - 输入参数
   - `@builtin(vertex_index)` 告诉GPU传入当前顶点的索引
   - `vertexIndex` 是参数名
   - `u32` 是无符号32位整数类型
   - 当GPU调用draw(6)时，这个函数会被调用6次，vertexIndex分别为：0, 1, 2, 3, 4, 5

3. `-> VertexOutput` - 返回类型
   - 函数必须返回我们之前定义的VertexOutput结构体

### vertex_index 工作机制

假设我们调用 `passEncoder.draw(6)`，GPU的执行过程：

```
调用次数     vertexIndex值     处理的顶点
第1次           0              positions[0] = (-0.6, -0.6)
第2次           1              positions[1] = (0.6, -0.6)
第3次           2              positions[2] = (0.6, 0.6)
第4次           3              positions[3] = (-0.6, -0.6)
第5次           4              positions[4] = (0.6, 0.6)
第6次           5              positions[5] = (-0.6, 0.6)
```

这6次调用是**并行**的，GPU会同时处理多个顶点以提高性能。

## 3.4 硬编码顶点数据详解

### 为什么使用硬编码？

**第3行：`var output: VertexOutput;`**
- 创建输出结构体的实例
- `var` 表示可变变量

**第6-13行：硬编码的顶点位置数组**

```wgsl
var positions = array<vec2f, 6>(
    vec2f(-0.6, -0.6),  // 左下
    vec2f(0.6, -0.6),   // 右下
    vec2f(0.6, 0.6),    // 右上
    vec2f(-0.6, -0.6),  // 左下
    vec2f(0.6, 0.6),    // 右上
    vec2f(-0.6, 0.6)    // 左上
);
```

#### 为什么在着色器中硬编码，而不是使用顶点缓冲区？

**硬编码的优点：**
1. **简单易学**：初学者不需要理解缓冲区、绑定组等复杂概念
2. **代码集中**：所有逻辑都在着色器中，便于调试
3. **快速原型**：适合简单的演示和测试

**硬编码的缺点：**
1. **不灵活**：数据固定在着色器中，无法动态修改
2. **不适合复杂模型**：真实3D模型有成千上万个顶点
3. **性能问题**：每次调用都要重新创建数组

**在生产环境中**，应该使用顶点缓冲区（后续章节会介绍）。

### 数组语法详解

```wgsl
var positions = array<vec2f, 6>(...)
```

- `array<vec2f, 6>` 表示：6个元素的数组，每个元素是vec2f类型
- `vec2f(-0.6, -0.6)` 创建一个二维向量，x=-0.6, y=-0.6

### 六个顶点的几何意义

这6个顶点定义了两个三角形，组成一个矩形：

```
屏幕坐标系（裁剪空间）：
    y
    ↑
    1
    |     5 ────── 2,4
    |     │       ／│
    |     │     ／  │
  0 |     │   ／    │
    |     │ ／      │
   -1     0,3 ──── 1
    |
    └────────────────→ x
   -1    0         1
```

**第一个三角形（逆时针）：**
- 顶点0: (-0.6, -0.6) 左下
- 顶点1: (0.6, -0.6)  右下
- 顶点2: (0.6, 0.6)   右上

**第二个三角形（逆时针）：**
- 顶点3: (-0.6, -0.6) 左下（重复）
- 顶点4: (0.6, 0.6)   右上（重复）
- 顶点5: (-0.6, 0.6)  左上

#### 为什么需要6个顶点而不是4个？

GPU只能绘制三角形。要绘制矩形，必须用两个三角形拼接：

```
方法1：重复顶点（我们的代码使用此方法）
┌─────┐
│ ╱ 2 │  需要6个顶点：0,1,2,3,4,5
│1 ╲  │  顶点0和3重复，顶点2和4重复
└─────┘

方法2：使用索引缓冲区（更高效，后续章节介绍）
┌─────┐
│ ╱   │  只需4个唯一顶点：0,1,2,3
│  ╲  │  索引数组：[0,1,2, 0,2,3]
└─────┘
```

## 3.5 裁剪空间坐标系详解

### 什么是裁剪空间？

**第15-16行：**
```wgsl
let pos = positions[vertexIndex];
output.position = vec4f(pos, 0.0, 1.0);
```

#### 第15行分析
- `let pos = positions[vertexIndex]`
- 使用vertexIndex从数组中获取对应的2D坐标
- `let` 表示不可变变量（相当于常量）
- pos的类型是 vec2f

#### 第16行分析
- `output.position = vec4f(pos, 0.0, 1.0)`
- 将2D坐标扩展为4D向量
- `vec4f(pos, 0.0, 1.0)` 等价于 `vec4f(pos.x, pos.y, 0.0, 1.0)`

**参数含义：**
- `pos.x, pos.y` - 从2D向量pos中取出x和y坐标
- `0.0` - z坐标（深度），0.0表示位于中间深度
- `1.0` - w坐标（齐次坐标），通常设为1.0

### 裁剪空间坐标系说明

WebGPU的裁剪空间使用标准化设备坐标（NDC）：

```
         y (↑)
         1
         |
    左上角 |     右上角
    (-1,1)------|-----(1,1)
         |      |
-1 ──────┼──────┼────── 1  x (→)
         |      |
   (-1,-1)------|----(1,-1)
    左下角 |     右下角
        -1

z轴：垂直于屏幕
  - z = -1: 近裁剪平面
  - z = 1:  远裁剪平面
  - z = 0:  中间位置（我们的矩形）
```

**重要特性：**
- x轴：-1（左边缘）到 1（右边缘）
- y轴：-1（底边缘）到 1（顶边缘）
- z轴：-1（近处）到 1（远处）
- 坐标原点(0,0)在屏幕中心

**我们的矩形顶点：**
- 范围：x: -0.6 到 0.6, y: -0.6 到 0.6
- 大小：1.2 × 1.2（在-1到1的范围内占60%）
- 位置：居中显示

## 3.6 UV坐标转换详解

### UV坐标系概念

UV坐标是纹理映射中使用的二维坐标系：

```
    v (↑)
    1 ┌──────────┐
      │          │
      │  纹理    │
    0 └──────────┘
      0          1  u (→)
```

**特点：**
- u轴：从左到右，0到1
- v轴：从上到下，0到1（注意：v=0在顶部）
- 原点(0,0)在左上角
- 范围总是归一化到[0,1]

### 坐标转换代码

**第19行：**
```wgsl
output.uv = vec2f((pos.x + 1.0) * 0.5, (1.0 - pos.y) * 0.5);
```

这行代码将裁剪空间坐标转换为UV坐标。让我们拆解这个公式：

#### U坐标转换：`(pos.x + 1.0) * 0.5`

**数学原理：**
```
裁剪空间 x: -1 到 1
         ↓ 加1.0
        0 到 2
         ↓ 乘0.5
UV空间 u: 0 到 1
```

**具体计算示例：**
```
pos.x = -1.0  →  u = (-1.0 + 1.0) * 0.5 = 0.0  (左边缘)
pos.x = -0.6  →  u = (-0.6 + 1.0) * 0.5 = 0.2  (我们矩形的左边)
pos.x =  0.0  →  u = (0.0 + 1.0) * 0.5 = 0.5   (中心)
pos.x =  0.6  →  u = (0.6 + 1.0) * 0.5 = 0.8   (我们矩形的右边)
pos.x =  1.0  →  u = (1.0 + 1.0) * 0.5 = 1.0   (右边缘)
```

#### V坐标转换：`(1.0 - pos.y) * 0.5`

**为什么要用 `1.0 - pos.y` 而不是 `pos.y + 1.0`？**

因为裁剪空间和UV空间的y轴方向相反：

```
裁剪空间 y轴：      UV空间 v轴：
    1 (上)           0 (上)
    ↑                ↓
    |                |
    0 (中)           0.5 (中)
    |                |
    ↓                ↓
   -1 (下)           1 (下)
```

**转换步骤：**
```
裁剪空间 y: -1 到 1
         ↓ 1.0 - y (反转)
        2 到 0
         ↓ 乘0.5
UV空间 v: 1 到 0
```

**具体计算示例：**
```
pos.y =  1.0  →  v = (1.0 - 1.0) * 0.5 = 0.0   (上边缘)
pos.y =  0.6  →  v = (1.0 - 0.6) * 0.5 = 0.2   (我们矩形的上边)
pos.y =  0.0  →  v = (1.0 - 0.0) * 0.5 = 0.5   (中心)
pos.y = -0.6  →  v = (1.0 - (-0.6)) * 0.5 = 0.8 (我们矩形的下边)
pos.y = -1.0  →  v = (1.0 - (-1.0)) * 0.5 = 1.0 (下边缘)
```

### 完整转换示例

让我们跟踪顶点0的完整转换过程：

```
1. 输入：vertexIndex = 0

2. 获取位置：pos = positions[0] = vec2f(-0.6, -0.6)

3. 设置裁剪空间位置：
   output.position = vec4f(-0.6, -0.6, 0.0, 1.0)

4. 计算UV坐标：
   u = (-0.6 + 1.0) * 0.5 = 0.4 * 0.5 = 0.2
   v = (1.0 - (-0.6)) * 0.5 = 1.6 * 0.5 = 0.8
   output.uv = vec2f(0.2, 0.8)

5. 返回：output（包含position和uv）
```

### 六个顶点的完整UV映射

```
顶点索引  裁剪空间位置        UV坐标
   0     (-0.6, -0.6)   →   (0.2, 0.8)  左下
   1     ( 0.6, -0.6)   →   (0.8, 0.8)  右下
   2     ( 0.6,  0.6)   →   (0.8, 0.2)  右上
   3     (-0.6, -0.6)   →   (0.2, 0.8)  左下（重复）
   4     ( 0.6,  0.6)   →   (0.8, 0.2)  右上（重复）
   5     (-0.6,  0.6)   →   (0.2, 0.2)  左上
```

可视化UV映射到矩形：

```
UV空间：                    裁剪空间：
v                          y
0  (0.2,0.2)──(0.8,0.2)    0.6  5─────2,4
   │            │          │    │  ╱  │
   │   矩形     │          │    │╱    │
   │            │          │    │     │
1  (0.2,0.8)──(0.8,0.8)   -0.6  0,3───1
   0          1  u              -0.6  0.6  x
```

### 练习4：理解顶点索引

添加调试代码，可视化顶点索引：

```wgsl
@vertex
fn vertexMain(@builtin(vertex_index) vertexIndex: u32) -> VertexOutput {
    var output: VertexOutput;

    var positions = array<vec2f, 6>(
        vec2f(-0.6, -0.6), vec2f(0.6, -0.6), vec2f(0.6, 0.6),
        vec2f(-0.6, -0.6), vec2f(0.6, 0.6),  vec2f(-0.6, 0.6)
    );

    let pos = positions[vertexIndex];
    output.position = vec4f(pos, 0.0, 1.0);

    // 根据vertexIndex生成不同的UV（用于观察每个顶点）
    // 偶数顶点用红色，奇数顶点用蓝色
    if (vertexIndex % 2u == 0u) {
        output.uv = vec2f(1.0, 0.0);  // 红色
    } else {
        output.uv = vec2f(0.0, 1.0);  // 蓝色
    }

    return output;
}
```

在片段着色器中使用这个UV：
```wgsl
@fragment
fn fragmentMain(input: VertexOutput) -> @location(0) vec4f {
    // 使用UV作为颜色
    return vec4f(input.uv, 0.0, 1.0);
}
```

## 3.8 常见问题解答

### Q1: 为什么position是vec4而不是vec2？

**答：** 这是齐次坐标系统的要求。
- vec4的第4个分量(w)用于透视投影
- 在后续的投影变换中，x、y、z都会除以w
- 对于2D图形，通常设w=1.0表示无透视

### Q2: 可以在顶点着色器中使用if语句吗？

**答：** 可以！WGSL支持完整的编程语法。
```wgsl
if (vertexIndex < 3u) {
    // 第一个三角形
} else {
    // 第二个三角形
}
```

### Q3: 为什么UV坐标需要反转Y轴？

**答：** 因为纹理坐标和屏幕坐标的Y轴方向相反：
- 屏幕坐标：Y轴向上为正
- 纹理坐标：V轴向下为正（图像的第一行在顶部）

### Q4: 可以输出更多数据到片段着色器吗？

**答：** 可以！在VertexOutput中添加更多@location字段：
```wgsl
struct VertexOutput {
    @builtin(position) position: vec4f,
    @location(0) uv: vec2f,
    @location(1) color: vec3f,      // 添加颜色
    @location(2) normal: vec3f,     // 添加法线
}
```

### Q5: 硬编码的数组是否每次调用都创建？

**答：** 理论上是，但GPU编译器会优化。实际上：
- 编译器可能将数组存储在着色器的常量内存中
- 对于大量顶点，应该使用顶点缓冲区（后续章节）

## 3.9 本章总结

### 核心概念

1. **顶点着色器是GPU并行处理的入口点**
   - 每个顶点执行一次
   - GPU同时处理多个顶点
   - 通过@builtin(vertex_index)获取当前顶点索引

2. **裁剪空间坐标系**
   - 范围：x、y、z都在-1到1之间
   - 原点在屏幕中心
   - 必须输出vec4f类型（齐次坐标）

3. **UV坐标系**
   - 用于纹理映射和渐变
   - 范围：0到1
   - 注意Y轴方向需要反转

4. **坐标转换公式**
   ```
   u = (x + 1.0) * 0.5      // 裁剪空间 → UV
   v = (1.0 - y) * 0.5      // 反转Y轴
   ```

### 顶点着色器的数据流

```
GPU发起draw调用
    ↓
并行启动多个顶点着色器实例
    ↓
每个实例：
  1. 接收 vertexIndex
  2. 获取对应顶点数据
  3. 计算裁剪空间位置
  4. 计算UV坐标
  5. 输出 VertexOutput
    ↓
传递给光栅化阶段
    ↓
插值生成片段数据
    ↓
传递给片段着色器
```

### 关键代码模式

**基本顶点着色器结构：**
```wgsl
@vertex
fn vertexMain(@builtin(vertex_index) index: u32) -> VertexOutput {
    // 1. 准备输出
    var output: VertexOutput;

    // 2. 获取或计算顶点位置
    let pos = /* 从缓冲区或硬编码获取 */;

    // 3. 设置裁剪空间位置（必须）
    output.position = vec4f(pos.x, pos.y, 0.0, 1.0);

    // 4. 计算其他属性（可选）
    output.uv = /* 计算UV坐标 */;

    // 5. 返回输出
    return output;
}
```
